# Password Manager

Консольный менеджер паролей на C++ для Windows. Приложение позволяет распределять учётные данные по папкам, добавлять и удалять записи, а также сохранять данные между запусками.

> [!WARNING]
> Текущая версия хранит логины и пароли в файле `passwords.txt` **в открытом виде, без шифрования**. Не используйте приложение для хранения настоящих паролей или других конфиденциальных данных. Проект находится на ранней стадии разработки и пока подходит только для обучения и экспериментов.

## Возможности

- создание папок для группировки записей;
- просмотр списка папок и количества записей в каждой из них;
- добавление сайта или программы, логина и пароля;
- просмотр сохранённых записей;
- удаление отдельных записей;
- удаление папки вместе со всем её содержимым;
- автоматическая загрузка данных при запуске;
- сохранение изменений в локальный файл;
- русскоязычный консольный интерфейс.

## Технологии

- C++;
- стандартная библиотека C++;
- Windows API для настройки UTF-8 в консоли;
- файловое хранение данных без сторонних зависимостей.

## Требования

- Windows;
- компилятор с поддержкой C++11 или новее:
  - MinGW-w64 / GCC;
  - Microsoft Visual C++ (MSVC);
  - другой совместимый компилятор для Windows.

Для приведённых ниже команд рекомендуется C++17.

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/dirreno-GH/PasswordManager.git
cd PasswordManager
```

### 2. Сборка

С помощью MinGW-w64 / GCC:

```bash
g++ -std=c++17 -Wall -Wextra -pedantic password_manager.cpp -o password_manager.exe
```

С помощью Developer Command Prompt for Visual Studio:

```bat
cl /EHsc /std:c++17 password_manager.cpp /Fe:password_manager.exe
```

### 3. Запуск

В PowerShell:

```powershell
.\password_manager.exe
```

В командной строке:

```bat
password_manager.exe
```

После запуска управление выполняется вводом номера нужного пункта меню.

## Как пользоваться

1. Выберите **«Создать папку»** и укажите её название, например `Работа` или `Социальные сети`.
2. Откройте созданную папку.
3. Выберите **«Добавить пароль»**.
4. Введите название сайта или программы, логин и пароль.
5. Используйте меню папки для просмотра или удаления записей.
6. При выходе данные будут сохранены автоматически.

## Хранение данных

Приложение создаёт файл `passwords.txt` в текущей рабочей папке — обычно рядом с исполняемым файлом, если программа запущена из каталога проекта.

В нём сохраняются:

- названия папок;
- сайты или программы;
- логины;
- пароли.

Файл необходим для восстановления данных при следующем запуске. Его ручное изменение может нарушить структуру данных и привести к ошибкам чтения.

> [!CAUTION]
> Не публикуйте `passwords.txt` в GitHub и не передавайте его другим людям: в текущей версии всё его содержимое доступно для чтения.

## Структура проекта

```text
PasswordManager/
├── password_manager.cpp   # исходный код приложения
├── README.md              # документация проекта
└── passwords.txt          # локальные данные, создаются при запуске
```

Основные сущности программы:

- `PasswordEntry` — запись с сайтом, логином и паролем;
- `Folder` — папка с названием и списком записей;
- `saveData()` и `loadData()` — сохранение и загрузка локальных данных;
- функции меню — создание, просмотр и удаление папок и записей.

## Текущие ограничения

- данные не шифруются;
- мастер-пароль и аутентификация отсутствуют;
- введённые пароли отображаются на экране;
- приложение работает только в консоли Windows;
- некорректный ввод вместо номера меню обрабатывается не во всех случаях;
- редактирование существующих папок и записей пока не реализовано;
- резервное копирование и восстановление отсутствуют.
